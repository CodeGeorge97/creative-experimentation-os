# Knowledge Quarantine

This directory contains restricted knowledge material whose authoritative
upstream provenance is not currently resolvable from the repository.

Until Phase 3C authors valid provenance records, knowledge entities here are
NOT_RETRIEVABLE.

After provenance is authored, quarantine material remains restricted to its
declared retrieval policy. Script-generation retrieval must refuse any path
containing a _quarantine segment.

This README is operator documentation and is not a KNOWLEDGE_ID entity.
