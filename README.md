# Estructura preliminar

Esta estructura de carpetas es **temporal**. Su único propósito es reunir y organizar las fuentes, la metodología y las muestras de estilo/voz antes de ejecutar el **Master Prompt** que dará inicio al desarrollo real del proyecto.

No contiene todavía diseño de arquitectura, Skills, ni ninguna Phase del sistema.

## Estructura

- `sources/` — material fuente sin procesar
  - `methodology/` — documentos de metodología
  - `original-books/` — libros originales de referencia
- `knowledge/` — conocimiento ya organizado/curado
  - `methodology/` — metodología procesada
  - `copywriting/schwartz/` — material de copywriting (Eugene Schwartz)
- `samples/` — muestras de referencia
  - `style-references/` — referencias de estilo (`ugc/`, `podcast/`, `animation/`)
  - `voices/chile/` — muestras de voz chilena (`female/`, `male/`)

## Próximo paso

Reunir las fuentes y muestras en estas carpetas. La arquitectura, los Skills y las Phases se definirán después, al ejecutar el Master Prompt.
